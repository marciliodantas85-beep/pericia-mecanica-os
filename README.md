# pericia-mecanica-os

Pacote de skills, referências, matrizes, checklists e templates para apoiar perícia judicial de engenharia mecânica no Codex.

## Estrutura

- `skills/`: skills Codex padronizadas com prefixo `pericia-`.
- `references/`: biblioteca global de fontes por tema.
- `tools/`: scripts de geração, renomeação e atualização dos artefatos.
- `PACOTE_CONHECIMENTO_CODEX.md`: pacote consolidado com árvore, skills, referências, templates, checklists e matrizes.
- `FONTES_OFICIAIS_ATUALIZAVEIS.md`: biblioteca de fontes oficiais e técnicas com rotina de atualização.
- `MATRIZ_MESTRA_CONHECIMENTO.md`: matriz geral de conhecimento por categoria, fonte, aplicação e skill.

## Uso no Codex

Para instalar localmente, copie as pastas de `skills/` para:

```powershell
C:\Users\<usuario>\.codex\skills
```

Depois reinicie o Codex para reindexar as skills.

## Regras de segurança

- Não inventar norma, artigo, decisão judicial ou edição de norma técnica.
- Separar fonte oficial, fonte técnica e fonte consultiva.
- Não reproduzir integralmente normas pagas, livros comerciais ou handbooks protegidos por licença.
- Marcar fontes temporais como `[VERIFICAR ANTES DE USO REAL]`.
- Validar CPC, CNJ, TJCE, Confea/Crea, ABNT, NR-12 e INMETRO antes de uso em processo real.
