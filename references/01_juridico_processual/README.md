# 01 - Jurídico processual

## Escopo

Fontes jurídicas processuais usadas para delimitar a atuação do perito judicial, prova pericial, prazos, quesitos, diligências, laudo, esclarecimentos, segunda perícia e deveres de imparcialidade.

## Fontes-base

- Código de Processo Civil - Lei 13.105/2015, texto compilado no Planalto.
- Jurisprudência oficial de tribunais superiores, quando usada como reforço argumentativo.
- Atos locais do tribunal competente, quando afetarem fluxo processual.

## Atualização

- Verificar semestralmente o CPC no Planalto.
- Verificar antes de qualquer petição, laudo ou checklist de prazo.
- Registrar artigos consultados, data de consulta, alteração legislativa e impacto nos modelos.

## Não fazer

- Não redigir conclusão jurídica no lugar do juiz.
- Não usar jurisprudência como regra automática sem aderência ao caso.
- Não misturar regra processual com recomendação técnica.
