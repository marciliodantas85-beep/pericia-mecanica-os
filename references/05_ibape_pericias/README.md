# 05 - IBAPE e perícias

## Escopo

Fontes do IBAPE Nacional e IBAPE/SP para boas práticas, cartilhas, glossários, boletins, normas institucionais, metodologia pericial, respostas a quesitos, relatório fotográfico e apresentação do laudo.

## Fontes-base

- Biblioteca do IBAPE Nacional.
- Boletins técnicos do IBAPE Nacional.
- Biblioteca digital do IBAPE/SP.
- Cartilhas, glossários e normas institucionais publicadas pelo IBAPE/SP.

## Atualização

- Verificar trimestralmente bibliotecas e boletins.
- Registrar título, entidade, autor, edição, data, status e link oficial.
- Classificar como boa prática ou fonte consultiva, salvo se houver incorporação normativa específica.

## Não fazer

- Não tratar cartilha como lei.
- Não usar orientação institucional como regra obrigatória sem fonte jurídica correspondente.
- Não misturar boas práticas de avaliação imobiliária com perícia mecânica sem adaptação técnica.
