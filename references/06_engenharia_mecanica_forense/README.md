# 06 - Engenharia mecânica forense

## Escopo

Base técnica de engenharia mecânica aplicada à perícia judicial: máquinas, componentes, instalações mecânicas, manutenção, operação, sistemas térmicos, transmissão de potência, confiabilidade e nexo técnico.

## Fontes-base

- Livros e manuais técnicos de engenharia mecânica.
- Manuais de fabricantes do equipamento litigioso.
- Normas técnicas aplicáveis ao objeto periciado.
- Dados de operação, manutenção, inspeção, reforma e histórico documental.

## Atualização

- Verificar por caso concreto, de acordo com máquina, componente, série, fabricante e data do fato.
- Registrar edição de livro, versão de manual, modelo, número de série, revisão técnica e limitações de aplicação.
- Conferir se a referência técnica é compatível com o equipamento real.

## Não fazer

- Não concluir nexo causal sem evidência material, documental ou metrológica suficiente.
- Não usar manual genérico quando o caso exige manual por modelo/série.
- Não extrapolar literatura técnica para condição operacional incompatível.
