# Checklist - Análise Documental Processual

Use antes de entregar saída da skill `pericia-02-analise-documental`.

- [ ] Autos e anexos listados
- [ ] Alegações principais extraídas
- [ ] Documentos vinculados a alegações
- [ ] Quesitos associados
- [ ] Datas e autoria conferidas
- [ ] Integridade e legibilidade avaliadas
- [ ] Certificados verificados
- [ ] Manuais do fabricante identificados
- [ ] Lacunas documentais listadas
- [ ] Conclusões marcadas como preliminares quando cabível

## Fechamento

- [ ] Fontes temporais marcadas como `[VERIFICAR ANTES DE USO REAL]`.
- [ ] Normas pagas não reproduzidas integralmente.
- [ ] Saída revisada contra `CRITERIOS_REVISAO.md`.
- [ ] Limitações registradas.
