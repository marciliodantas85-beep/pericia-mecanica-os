# Checklists - Matriz de Quesitos

## Consolidação
- [ ] Todos os quesitos do juízo listados
- [ ] Todos os quesitos das partes listados
- [ ] Quesitos suplementares reservados
- [ ] Numeração original preservada
- [ ] Origem de cada quesito identificada

## Classificação técnica
- [ ] Tema técnico identificado
- [ ] Método necessário definido
- [ ] Evidência mínima vinculada
- [ ] Fonte normativa/técnica selecionada
- [ ] Quesito jurídico/impertinente marcado com ressalva

## Pré-laudo
- [ ] Nenhum quesito deferido sem resposta
- [ ] Respostas não contradizem análise
- [ ] Limitações vinculadas aos quesitos afetados
- [ ] Fotos/tabelas/anexos citados nas respostas
