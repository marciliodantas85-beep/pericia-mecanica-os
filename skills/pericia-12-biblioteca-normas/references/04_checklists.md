# Checklists - Biblioteca de Normas e Métodos

## Entrada de nova fonte
- [ ] Fonte oficial localizada
- [ ] Natureza classificada
- [ ] Edição/versão registrada
- [ ] Data de consulta anotada
- [ ] Licença/copyright avaliado
- [ ] Skills impactadas mapeadas
- [ ] Necessidade de verificação periódica marcada

## Revisão periódica
- [ ] CPC/CNJ conferidos
- [ ] TJCE portarias e tabelas conferidas
- [ ] Confea/Crea conferidos
- [ ] NR-12 conferida
- [ ] ABNT edição/catálogo conferidos
- [ ] IBAPE edição/status conferidos
- [ ] Jurisprudência relevante atualizada

## Uso seguro
- [ ] Obrigatória x consultiva diferenciado
- [ ] Norma paga não copiada
- [ ] Fonte revogada sinalizada
- [ ] Fonte local não generalizada
- [ ] Opinião/literatura não tratada como lei
